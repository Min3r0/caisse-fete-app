# Consignes pour les assistants IA

Lire et respecter `CONTRIBUTING.md`. En résumé :
- Appli PWA statique sans build : `index.html`, `manifest.webmanifest`, `sw.js`, icônes PNG.
- Données stockées uniquement dans le navigateur du téléphone : ne jamais casser la compatibilité des données déjà enregistrées.
- Chemins relatifs uniquement ; tout nouveau fichier va dans `FICHIERS` de `sw.js`.
- Commits Conventional Commits en français, une branche par changement, PR vers `main`.
