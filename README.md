# Caisse — comité des fêtes

Application installable (PWA) qui fonctionne sans connexion : fonds de caisse et mouvements d'argent pendant la fête.

**Appli en ligne :** https://VOTRE-PSEUDO.github.io/caisse-fete-app/

## Installer sur le téléphone
1. Ouvrir l'adresse ci-dessus dans Chrome (Android) ou Safari (iPhone).
2. Android : menu ⋮ → « Installer l'application ». iPhone : Partager → « Sur l'écran d'accueil ».

## Mettre à jour
Pull Request vers `main` → fusion → publication automatique (GitHub Actions).
Les téléphones récupèrent la nouvelle version à la prochaine ouverture avec réseau.

## Sauvegarde
Bouton « Sauvegarde et export » → « Sauvegarder les données », chaque soir de fête.
Effacer les données de navigation efface les saisies.
